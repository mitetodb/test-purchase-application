# Mystery-Shopper-Benutzerhandbuch

Willkommen! Dieses Handbuch ist für **Mystery Shopper**, die zugewiesene Testkäufe durchführen.

## Ihre Rolle

Als **Mystery Shopper** können Sie:

✅ **Folgendes tun:**
- Ihnen zugewiesene Testkäufe anzeigen
- Status Ihrer Zuweisungen aktualisieren
- Anhänge hochladen (Fotos, Belege, Berichte)
- Kommentare zu Statusänderungen hinzufügen
- Geschäfte anzeigen
- Ihr eigenes Profil bearbeiten

❌ **Nicht tun:**
- Zuweisungen anderer Shopper sehen
- Testkäufe erstellen
- Sich selbst Käufe zuweisen
- Alle Kunden anzeigen
- Geschäfte oder Kunden erstellen oder bearbeiten
- Käufe sehen, die Ihnen nicht zugewiesen sind

**Wichtig:** Ihr Name ist vertraulich. Kunden und Vertriebsleiter können Ihre Identität nicht sehen - nur Administratoren und Kundenbetreuer können dies.

## Zuweisungs-Workflow

Wenn Ihnen ein Kauf zugewiesen wird, durchläuft er diese Status:

```
ZUGEWIESEN → IN BEARBEITUNG → ABGESCHLOSSEN
```

### Schritt 1: ZUGEWIESEN

Sie erhalten eine neue Zuweisung:
1. Überprüfen Sie die E-Mail-Benachrichtigung (falls aktiviert)
2. Melden Sie sich an und sehen Sie sich den Kauf an
3. Überprüfen Sie:
   - Geschäftsstandort
   - Zu bewertende Artikel
   - Fälligkeitsdatum
   - Spezielle Anweisungen
   - Angehängte Materialien
4. Akzeptieren Sie die Zuweisung, indem Sie den Status auf **IN BEARBEITUNG** ändern

### Schritt 2: IN BEARBEITUNG

Sie arbeiten an der Zuweisung:
1. Besuchen Sie das Geschäft
2. Bewerten Sie die angegebenen Artikel/Dienstleistungen
3. Machen Sie Fotos (falls erforderlich)
4. Sammeln Sie Belege
5. Machen Sie Notizen für Ihren Bericht

### Schritt 3: ABGESCHLOSSEN

Sie sind fertig:
1. Laden Sie alle erforderlichen Dateien hoch:
   - Belegfotos
   - Geschäftsfotos
   - Produkt-/Dienstleistungsfotos
   - Schriftlicher Bericht (PDF)
2. Ändern Sie den Status auf **ABGESCHLOSSEN**
3. Fügen Sie abschließende Kommentare hinzu, die Ihre Ergebnisse zusammenfassen
4. Aktivieren Sie die E-Mail-Benachrichtigung, um den Kundenbetreuer zu informieren
5. Klicken Sie auf **Speichern**

Der Kundenbetreuer wird Ihre Arbeit überprüfen.
