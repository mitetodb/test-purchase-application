# Vertriebsleiter-Benutzerhandbuch

Willkommen! Dieses Handbuch ist für **Vertriebsleiter** mit Nur-Lese-Zugriff zum Anzeigen von Testkäufen und Erstellen von Berichten.

## Ihre Rolle

Als **Vertriebsleiter** können Sie:

✅ **Folgendes tun:**
- Alle Testkäufe anzeigen
- Alle Kunden anzeigen
- Alle Geschäfte anzeigen
- Berichte und Analysen erstellen
- Statusverlauf anzeigen
- Anhänge anzeigen
- Ihr eigenes Profil bearbeiten

❌ **Nicht tun:**
- Testkäufe erstellen oder bearbeiten
- Mystery Shopper zuweisen
- **Mystery-Shopper-Namen sehen** (vertraulich)
- Kunden/Geschäfte/Benutzer erstellen oder bearbeiten
- Kaufstatus ändern
- Daten löschen

**Wichtig:** Mystery-Shopper-Namen sind ausgeblendet, um die Vertraulichkeit zu wahren. Stattdessen sehen Sie "Mystery Shopper" oder "Zugewiesen".
