# Sales Manager User Guide

Welcome! This guide is for **Sales Managers** who have read-only access to view test purchases and generate reports.

## Your Role

As a **Sales Manager**, you:

✅ **Can do:**
- View all test purchases
- View all customers
- View all shops
- Generate reports and analytics
- View status history
- View attachments
- Edit your own profile

❌ **Cannot do:**
- Create or edit test purchases
- Assign mystery shoppers
- **See mystery shopper names** (confidential)
- Create or edit customers/shops/users
- Change purchase status
- Delete any data

**Important:** Mystery shopper names are hidden to maintain confidentiality. You'll see "Mystery Shopper" or "Assigned" instead.

## Getting Started

### Logging In

1. Go to https://testkauf.getinweb.de
2. Enter your username and password
3. Click **Login**

### Your Profile

1. Click your username → **Profile**
2. Update email, country, language, avatar
3. Change password if needed
4. Click **Save**

## Dashboard

Your dashboard shows:
- **Total Purchases**: Count by status
- **Recent Purchases**: Latest activity
- **Top Customers**: By purchase volume
- **Trends**: Charts and graphs

## Viewing Test Purchases

1. Click **Test Purchases**
2. View all purchases (read-only)
3. See details:
   - Customer name
   - Shop location
   - Status and history
   - Items and pricing
   - Attachments
   - **Mystery Shopper**: Shows "Assigned" (name hidden)
4. Filter by status, customer, date, shop

## Viewing Customers

1. Click **Customers**
2. See all customers (read-only)
3. View customer details, but cannot edit

## Viewing Shops

1. Click **Shops**
2. See all shop locations (read-only)
3. Search by name, city, or country

## Reports and Analytics

This is your primary function.

### Generating Reports

1. Go to **Reports**
2. Select report type:
   - Purchase summary
   - Customer activity
   - Shop performance
   - Status distribution
   - Time-based trends
3. Set filters:
   - Date range
   - Customer
   - Shop
   - Status
4. Click **Generate**
5. Export to CSV or PDF (if available)

### Key Metrics

Monitor:
- Total purchases per period
- Average completion time
- Purchase value trends
- Customer activity levels
- Shop visit frequency
- Status distribution

### Analytics

Use insights for:
- Identifying trends
- Supporting sales decisions
- Forecasting demand
- Customer relationship insights
- Performance benchmarking

## Attachments

View attachments on purchases:
1. Open a test purchase
2. Scroll to **Attachments**
3. View or download files

You cannot upload or delete attachments.

## Status History

1. Open a test purchase
2. View **Status History**
3. See who changed status and when
4. Note: User names visible, but shopper names are not

## Best Practices

### Reporting

- Generate regular reports for stakeholders
- Track trends over time
- Document insights and patterns
- Share findings with management

### Analysis

- Compare periods (month-over-month, year-over-year)
- Identify top-performing customers
- Monitor completion rates
- Look for bottlenecks in workflow

### Data Privacy

- Respect shopper anonymity
- Don't share confidential data
- Use reports appropriately
- Maintain data security

- `Alt + H`: Dashboard
- `Alt + T`: Test Purchases
- `Alt + C`: Customers
- `Alt + S`: Shops
- `Alt + R`: Reports
- `Alt + P`: Profile
